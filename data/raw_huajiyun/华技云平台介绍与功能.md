# 华技云·华为ICT智慧实训平台 介绍与功能

## 一、平台是什么
华技云是依托山东省第4家"领先级华为ICT学院"官方资源，自主研发的**华为ICT"岗课赛证"一体化智慧实训平台**。它以"云端沙箱实训 + 自研AI助学智能体"为双引擎，深度打通华为 HCIA / HCIP / HCIE 全层级认证体系、华为云全真实训环境、华为ICT大赛赛事体系与生态伙伴就业渠道，是全国首个实现华为官方数据互通、学分互认、云端实训、岗证对接的专属智慧助学实训系统。平台由德州工程职业学院学生团队研发，已在校内ICT专业班级试点运行。

## 二、要解决的核心痛点
1. **证教脱节**：华为认证考点迭代快于教材，学生所学与考试/岗位不匹配，行业HCIA通过率仅30%–40%。
2. **实训成本高**：搭建云计算/鲲鹏/昇腾等全真实训环境需上百万硬件投入，多数院校无力承担。
3. **数据割裂**：课程、实训、认证、竞赛成绩分散，无法形成统一学生技能画像。
4. **就业断层**：生态伙伴海量岗位与学生持证输出存在信息差。

## 三、四大核心模块
1. **助学智能体"华小智"（AI督学）**
   - 页面驻留监测、走神识别、挂机预警、实时弹窗提醒，杜绝线上无效学习。
   - 基于面部特征追踪与动态肢体分析，毫秒级识别瞌睡、走神、离席等行为。
   - 拆解 1200+ 可量化技能点，提供分层知识点精讲、错题归类、薄弱点推送、个性化学习路径。
   - 自动生成专注度报告与班级学情数据驾驶舱，辅助教师精准施教。

2. **华为全层级认证学习模块**
   - 实时同步 HCIA / HCIP / HCIE 全方向官方最新题库与考点，覆盖云计算、大数据、人工智能、网络技术、鸿蒙、欧拉等12个主流方向。
   - 功能：分层刷题、专项突破、全真模考、错题复盘、知识点溯源。
   - 与华为HALP授权培训中心合作，平台考核成绩可与校内课程学分互认，优秀学生可申请华为认证笔试免考推荐。

3. **华为云全真云端实训模块**
   - 通过API深度对接华为云沙箱实验室，零本地部署、按需使用、按需付费。
   - 学生用浏览器即可使用华为云Stack、鲲鹏服务器、昇腾AI芯片等企业级最新技术栈，环境与生产一致。
   - 全程记录操作轨迹，生成标准化实训报告，过程可追溯、可监管、可考核。
   - 已完成龙芯处理器架构信创服务器全栈适配（硬件→统信UOS/麒麟→华为云实训环境），践行国家信创战略。

4. **华为赛事与生态就业模块**
   - 内置华为大学生ICT大赛、蓝桥杯华为赛道、全国职业院校技能大赛华为赛项专区，整合真题、培训、模拟环境。
   - 联动华为ICT人才联盟，认证获取后通过华为人才生态API自动匹配10万+生态伙伴岗位，实现"持证即上岗"。
   - 引入生态企业真实小型项目，完成实训可获企业认证与实习机会。

## 四、技术架构（给学生/老师了解）
- 后端：Spring Boot（Java），使用 Spring Data JPA、Spring Security + JWT 鉴权、MySQL（本地也可H2）。
- 前端：页面内嵌于 `static/` 目录，随后端单体部署，无需单独部署前端。
- AI对话：提供非流式与 SSE 流式两种接口；双引擎——优先本地大模型 Ollama（qwen2.5:3b），不可用时自动降级到内置知识库引擎，永不"哑火"。
- 部署：支持 Docker 部署到 Zeabur 等云平台，数据库配置通过环境变量注入。

## 六、试点成效（数据可量化）
- HCIA认证通过率从行业平均35%跃升至98%（提升2.8倍）。
- 学生无效学习时长减少60%以上，刷题正确率显著提升。
- 已获2人HCIP认证、申请2项软件著作权。
- 备考周期从3个月+缩短至1个月以内。
